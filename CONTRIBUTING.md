# Contributing to mcp-joplin

Thanks for taking the time to help.

## Issues

Search the existing issues before opening a new one. For a bug, say what you
did, what you expected, and what happened instead, with versions and the
smallest example that shows it.

Security problems don't go in issues: see [SECURITY.md](SECURITY.md).

## Pull requests

- Open an issue first for anything larger than a small fix, so we can agree
  on the approach before you spend time on it.
- Keep each pull request to one change, and include tests where they make
  sense.
- Make sure the checks pass. Every change to `main` goes through a
  pull request, and is reviewed before it's merged.

By contributing, you agree that your contribution is licensed under this
repository's licence.
