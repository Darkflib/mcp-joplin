# Security policy

## Reporting a vulnerability

Please don't report security problems in a public issue.

Use GitHub's private reporting instead: on this repository's **Security**
tab, choose **Report a vulnerability**. If that option isn't there, open an
issue that asks for a private contact, without any details of the problem.

You should get a reply within a week. If the report is confirmed, the fix is
released first and the advisory is published after it.

## Supported versions

Only the latest version on the `main` branch gets security fixes.
